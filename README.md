# 토르티야 정상회담

작은 가상 나라 대표들이 국제 연합의 공동 구조선을 만들려 모였는데, 회의판이 거대하고 바삭한 토르티야다.
판의 금을 골라 쪼개어 **공동 작업을 방해하는 손**은 떼어 놓고, **함께 일해야 하는 동료**는 같은 조각에 남겨라.
한 번 깬 판은 다시 붙지 않는다.

## 실행

빌드 과정이 없다. `index.html`을 브라우저로 열면 된다.

- 데스크톱: 파일을 바로 열면 휴대폰 크기의 세로 화면으로 표시된다.
- 휴대폰: 같은 폴더를 아무 정적 서버로 띄우고 접속한다 (예: `npx serve .`).
- 글꼴과 소리는 모두 내장되어 있어 오프라인에서도 동작한다.

## 조작 (터치·마우스 동일)

| 동작 | 결과 |
| --- | --- |
| 금을 누른다 | 실제로 갈라질 길이 빛난다. 끝점의 노란 점은 이미 벌어진 틈에서 멈추는 곳 |
| 누른 채로 손을 뗀다 | 그 길을 따라 바삭하게 쪼개진다 |
| 누른 채 금에서 멀리 끌고 뗀다 | 취소 |
| 대표를 누른다 | 지금 무엇을 하는지 짧게 말한다 |
| `새 토르티야` (또는 R 키) | 같은 회의를 처음부터 |

## 규칙

- 공동 작업(판자 들기, 돛대 받치기, 깃발 펴기, 노 건네기, 조타륜 잡기 …)은 팀 전원이 **같은 조각**에 있을 때만 이어진다.
- 같은 조각에서 그 소품을 붙잡거나 반대로 당기는 대표가 있으면 작업이 멈춘다. 다른 조각으로 떼어 내면 손이 놓인다.
- 작업이 끝나기 전에 팀이 갈라지면 그 작업은 영영 이어 갈 수 없다. **끝난 작업의 팀은 갈라져도 괜찮다.**
- 금은 이미 벌어진 틈을 건너지 못한다. 그래서 금을 깨는 순서와 누르는 위치에 따라 갈라지는 길이 달라진다.
- 일부 대표는 떼어 놓으면 같은 조각의 다른 미완료 작업을 찾아 걸어간다 (참견꾼).
- 남은 금으로 더는 합의할 수 없게 되면 회의가 정회되고 이유를 알려 준다. 두 번 정회되면 `의장의 귀띔`을 쓸 수 있다.

## 회의 (7개)

1. 첫 안건 — 기본: 방해꾼만 떼어 놓기
2. 표정보다 손 — 찌푸린 얼굴의 조력자, 웃는 얼굴의 방해꾼
3. 끝난 일은 놓아도 된다 — 작업이 끝나길 기다린 뒤 가르기
4. 틈에서 멈추는 금 — 이미 갈라진 판, 누르는 쪽에 따라 다른 결과
5. 두 손의 대표 — 한 손으로 돕고 한 손으로 방해하는 대표
6. 참견꾼 — 떼어 놓으면 다른 작업으로 걸어가는 대표
7. 정상회담 — 종합

회의를 마칠 때마다 식탁 위 물그릇의 구조선에 부품이 더해진다.

## 구조

```
index.html        진입점 (고전 스크립트만 사용 → file:// 에서도 동작)
css/style.css     화면 배치와 카드
css/fonts.css     게임에 쓰인 글자만 남긴 고운바탕·고운돋움 (base64, 생성 파일)
js/util.js        수학·난수·노이즈
js/geom.js        금 네트워크 → 면 → 조각 계산, 금이 갈라지는 구간(틈에서 멈춤)
js/sim.js         규칙 시뮬레이션과 너비 우선 해법 탐색 (정회 판정·귀띔에도 사용)
js/levels.js      나라·부품·회의 데이터
js/tortilla.js    구운 표면 텍스처, 두께와 단면, 금 그리기
js/diplomat.js    외교관 그리기 (구두·손·어깨·시선·표정)
js/props.js       판자·돛·깃발·노·조타륜·구명환·닻·만국기·등불
js/ship.js        물그릇과 구조선
js/fx.js          부스러기, 말풍선, 날아가는 부품
js/audio.js       WebAudio 합성음 (바삭함, 발걸음, 밧줄, 음악)
js/ui.js          DOM 인터페이스
js/main.js        게임 루프, 입력, 연출, 흐름
tools/solve.js    모든 회의의 해법·함정 검증: node tools/solve.js
tools/shot.js     Playwright 스크린샷 도구
tools/build_fonts.py  글꼴 부분 집합 생성
```
